## 1. 成本测算前提

本测算按优化后的产品路线估算：

> 先做本地运行的 AI 辅助面部行为视频标注工具，不做云端大平台、不训练大模型、不做情绪/测谎判断。

核心假设：

- 第一版以本地分析为主。
- 默认不采购 Noldus/iMotions 等商业研究平台。
- 默认不训练自有深度模型。
- 默认不做云端 SaaS、账号、多租户、权限系统。
- 默认优先使用商业友好的开源依赖。
- 汇率按 `1 USD ≈ 6.8 RMB` 粗略估算；实际以付款日汇率为准。

成本分为两类：

- 现金成本：硬件、云、软件、测试用户、法律合规、外包。
- 机会成本/人力成本：团队成员投入时间折算。

## 2. 总体预算结论

| 阶段 | 周期 | 目标 | 推荐团队 | 预算区间 |
|---|---:|---|---|---:|
| P0 技术 Spike | 2-3 周 | 跑通视频 -> 特征 -> 候选事件文件 | 1 名全栈/CV 工程师 | 现金 0.5-2 万；含人力 3-8 万 |
| P1 可演示 MVP | 6-8 周 | 本地服务 + 时间线 UI + 人工标注 + 导出 | 1 全栈 + 0.5 CV/ML | 现金 2-8 万；含人力 15-35 万 |
| P2 试点 Beta | 3 个月 | 可安装、可试点、批处理、报告、错误处理 | 2 工程 + 0.5 产品/QA | 含人力 45-90 万 |
| P3 商业化 V1 | 6-9 个月 | 桌面交付、私有化、合规、客户支持 | 4-6 人小队 | 含人力 150-350 万 |

如果是创始人自己开发，前 6-8 周真实现金支出可以压到 **2-5 万 RMB**；但如果按市场人力成本核算，MVP 的真实投入通常在 **15-35 万 RMB**。

## 3. 人力成本

### 3.1 推荐最小团队

P0/P1 阶段最小配置：

- 1 名全栈工程师：Python、React、视频处理、本地应用。
- 0.5 名 CV/ML 工程师：MediaPipe/OpenCV、特征提取、事件检测、评测。
- 0.2 名产品/设计/QA：用户流程、试点访谈、测试样例。

如果只能一个人做，最好是“Python + React + 一点 CV”的全栈，而不是纯算法工程师。因为第一版的胜负手在工作流闭环，不在模型 SOTA。

### 3.2 人力成本假设

按国内一线/新一线城市的全成本粗略估：

| 角色 | 月全成本估算 |
|---|---:|
| 高级全栈工程师 | 4.5-7.5 万 RMB/月 |
| CV/ML 工程师 | 5-9 万 RMB/月 |
| 产品/设计/QA 兼职折算 | 1.5-4 万 RMB/月 |
| FACS/心理学顾问 | 500-2000 RMB/小时，或按项目 1-5 万 |

P1 8 周参考计算：

```text
全栈工程师 2 个月：9-15 万
CV/ML 0.5-1 人 2 个月：5-18 万
产品/设计/QA 兼职：1-4 万
硬件/测试/云/杂项：2-8 万
合计：17-45 万
推荐控制目标：15-35 万
```

## 4. 硬件成本

### 4.1 开发机

MVP 不一定需要高端 GPU。MediaPipe、OpenCV、规则检测在普通 CPU 或中端 GPU 上即可开发。

| 配置 | 适用场景 | 预算 |
|---|---|---:|
| 现有普通开发机 | P0 验证、短视频样例 | 0 |
| CPU 强一点的开发机，32GB RAM，1TB SSD | 本地视频处理、前后端开发 | 8000-15000 RMB |
| RTX 4060/4070 工作站或笔记本 | 本地推理、轻量模型实验 | 10000-20000 RMB |
| RTX 4080/4090 工作站 | 后续深度模型实验、批处理 | 20000-40000 RMB |

推荐：

- P0/P1：优先使用现有机器；如需采购，买一台 32GB RAM + 1TB SSD + 中端 NVIDIA GPU 的机器即可。
- P2 以后：再考虑 4090 工作站或云 GPU。

### 4.2 采集与测试设备

| 设备 | 用途 | 预算 |
|---|---|---:|
| 普通 webcam | 模拟真实用户测试视频 | 200-800 RMB |
| 60fps/120fps 摄像头 | 更适合短时面部变化测试 | 800-5000 RMB |
| 补光灯/三脚架 | 稳定采集条件 | 300-2000 RMB |
| 移动硬盘/NAS | 保存测试视频和项目文件 | 500-5000 RMB |

P1 不建议一上来买昂贵高速相机。先用普通 webcam 和手机视频验证产品工作流，再决定是否建设高帧率样本。

## 5. 云资源成本

### 5.1 MVP 阶段原则

MVP 尽量不依赖云 GPU。云只用于：

- 偶尔跑批量测试。
- 对比不同模型。
- 临时处理大视频。
- 远程演示环境。

不要在第一阶段做常驻 GPU 服务。

### 5.2 价格参考

2026 年 5 月附近，云 GPU 价格波动较大。官方页面通常按地区、机器规格、磁盘、网络另算。

参考：

- RunPod 官方价格页显示按 GPU 小时计费，适合短时实验和弹性测试：https://www.runpod.io/pricing/
- Google Cloud GPU pricing 官方说明 GPU 会在 VM 机器费用之外单独计费，并按区域变化：https://cloud.google.com/compute/gpus-pricing
- AWS EC2 On-Demand pricing 官方页面按实例和区域计费：https://aws.amazon.com/ec2/pricing/on-demand/

粗略预算：

| 用法 | GPU 时间 | 估算成本 |
|---|---:|---:|
| P0 偶尔实验 | 20-50 小时 | 100-500 RMB |
| P1 批量测试 | 100-300 小时 | 500-3000 RMB |
| P2 试点批处理 | 300-1000 小时 | 2000-10000 RMB |

如果上 AWS/GCP/Azure 大厂按需 GPU，成本通常高于 RunPod/Vast 这类 GPU 云市场。早期建议以本地机器 + 低频云 GPU 为主。

## 6. 软件与许可证成本

### 6.1 推荐默认免费/开源栈

MVP 默认无需购买商业软件。

| 类型 | 推荐 |
|---|---|
| 前端 | React、TypeScript、Vite |
| 本地服务 | Python、FastAPI |
| 视频处理 | FFmpeg、OpenCV、PyAV |
| 特征提取 | MediaPipe |
| 数据处理 | NumPy、Pandas/Polars、SciPy、PyArrow |
| 存储 | SQLite、Parquet/CSV/JSON |
| 测试 | pytest、Playwright |
| 打包 | 后续 Electron/Tauri |

### 6.2 许可证风险

| 依赖 | 成本 | 风险 | 建议 |
|---|---:|---|---|
| MediaPipe | 免费 | Apache 2.0 相对友好，但具体模型仍要记录版本 | MVP 默认 |
| Py-Feat | 免费 | MIT，但模型和依赖需核查 | 内部 baseline 或可选 |
| OpenFace | 商业授权不明 | 官方许可证偏 noncommercial research use | 不默认打包 |
| LibreFace | 商业授权不明 | README 明确 non-commercial toolbox | 不默认打包 |

发布商业版前建议做一次许可证审计，预算 **5000-20000 RMB**。

### 6.3 桌面发布相关成本

如果后续做桌面版：

| 项目 | 预算 |
|---|---:|
| Apple Developer Program | 99 USD/年 |
| Windows 代码签名证书 | 约 2000-6000 RMB/年，取决于类型和供应商 |
| 崩溃/日志服务 | 免费档到数百 RMB/月 |
| 官网域名和托管 | 100-1000 RMB/年 |

P0/P1 不需要先花这笔钱。

## 7. 数据与标注成本

### 7.1 Golden Set

建议从第一天建立小型测试集：

- 3 段高质量正脸视频。
- 3 段普通 webcam 视频。
- 2 段头动明显视频。
- 2 段低光/遮挡/模糊视频。
- 2 段说话口型明显视频。

成本：

| 方式 | 成本 |
|---|---:|
| 团队自采 | 0-2000 RMB |
| 找 10-30 名被试 | 5000-20000 RMB |
| FACS 专业标注 | 2-10 万 RMB，取决于视频时长和标注深度 |

P1 不建议做大规模 FACS 标注。先做“候选事件是否能帮用户省时间”的验证。

### 7.2 用户访谈与试点

| 项目 | 成本 |
|---|---:|
| 3-5 个专家访谈激励 | 1000-5000 RMB |
| 1-2 个实验室试点支持 | 5000-30000 RMB |
| 定制导出格式/报告模板 | 主要是人力成本 |

## 8. 合规与法律成本

MVP 内测阶段：

- 隐私说明。
- 被试授权模板。
- 数据删除机制说明。
- 不适用场景声明。
- 开源许可证清单。

预算：**5000-30000 RMB**。

如果进入企业试点：

- 用户协议。
- 隐私政策。
- 数据处理协议。
- 本地部署合规说明。
- 生物识别/敏感个人信息处理评估。

预算：**2-10 万 RMB**。

不建议第一阶段进入 HR、教育监控、医疗诊断、安防审讯等高合规成本场景。

## 9. 推荐技术栈

### 9.1 P0/P1 推荐栈

后端/分析引擎：

- Python 3.11 或 3.12
- FastAPI
- Pydantic
- OpenCV
- FFmpeg / PyAV
- MediaPipe
- NumPy
- SciPy
- Pandas 或 Polars
- PyArrow / Parquet
- SQLite
- pytest

前端：

- React
- TypeScript
- Vite
- TanStack Query
- Zustand 或 Redux Toolkit
- Canvas/SVG 时间线
- uPlot、ECharts 或自研轻量曲线组件
- Playwright

数据格式：

- `manifest.json`
- `run.json`
- `features.parquet` 或 `features.csv`
- `events.json`
- `annotations.json`
- `quality.json`

开发工具：

- uv 或 Poetry 管 Python 依赖。
- pnpm 管前端依赖。
- Ruff + mypy/pyright 做 Python 质量。
- ESLint + Prettier 做前端质量。

### 9.2 后续桌面版技术栈

优先建议：

- Electron + electron-builder
- React UI 复用
- Python analysis engine 作为本地子进程
- 本地 HTTP/WebSocket 通信

原因：

- Windows 交付和调试更快。
- Python 子进程管理资料多。
- 对早期商业试点更务实。

Tauri 可以作为后续优化选项，但不建议在 P0/P1 把时间耗在桌面壳选型上。

### 9.3 后续算法增强栈

等 P1 验证后再加：

- ONNX Runtime：模型部署统一。
- PyTorch：研究和训练，不一定进发布包。
- scikit-learn：候选事件排序 baseline。
- DuckDB：本地分析查询。
- MLflow 或轻量自研 run registry：模型实验记录。

暂缓：

- Kubernetes。
- 云端多租户。
- 实时流媒体服务。
- 大模型训练平台。
- 移动端 SDK。

## 10. 成本控制建议

第一阶段省钱的关键不是少买 GPU，而是少做不该做的范围。

必须砍掉：

- 情绪识别准确率竞赛。
- 自研深度模型。
- 完整桌面安装包。
- 云端账号/权限/计费。
- 多人协作。
- SDK。

必须保留：

- 统一数据 schema。
- 视频特征提取。
- 候选事件检测。
- 时间线 UI。
- 人工标注。
- 导出。
- 质量门控。

推荐预算线：

| 情况 | 建议预算 |
|---|---:|
| 创始人自研 6 周 | 现金 2-5 万 |
| 小团队做 8 周 MVP | 15-35 万 |
| 做到可试点 Beta | 45-90 万 |
| 做商业 V1 | 150-350 万 |

## 11. 商业回本粗算

如果 P1/P2 投入 50 万 RMB，要验证商业闭环，可以有三种路径：

| 收费方式 | 单价假设 | 回本所需 |
|---|---:|---:|
| 实验室年费 | 2-5 万/年 | 10-25 个实验室 |
| 企业 UX/广告试点 | 5-15 万/项目 | 4-10 个项目 |
| 私有化部署 | 20-50 万/年 | 1-3 个客户 |

早期最现实的是：

- 找 1-2 个实验室做低价/免费试点拿反馈。
- 找 1 个企业 UX/广告测试团队做付费试点。
- 不急着做标准 SaaS 订阅。

## 12. 最终建议

最低成本、最高确定性的开工路线：

1. 先用现有机器 + MediaPipe 跑通 `facecat analyze input.mp4 --out project.facecat`。
2. 只做本地 React UI，不先封桌面壳。
3. 只做候选事件和人工标注，不做情绪判断。
4. 第一阶段云 GPU 预算控制在 3000 RMB 内。
5. 第一阶段现金预算控制在 2-5 万 RMB；如果按人力核算，MVP 控制在 15-35 万 RMB。

这条路线最不烧钱，也最能快速验证 FaceCat 有没有真实用户价值。
